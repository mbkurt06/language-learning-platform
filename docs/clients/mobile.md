# Mobile Client

The mobile app is an Expo/React Native client of Platform API.

Planned modules:
- learning list and encounter history
- daily review/quiz
- media discovery via provider catalog
- embedded/deep-linked playback where provider rules allow it
- interactive transcript/subtitle UI
- automatic learned-item hints using analyze-and-match

Playback support is provider capability-driven; the app must not assume every provider allows embedding.
